# 傀異研究ノート

モンスターハンターライズ：サンブレイクの傀異研究レベルについて、現在レベルと目標レベルから自動計算した必要ポイントで目標到達までのポイントと周回数を試算する日本語の静的サイトです。

## 起動

`index.html` をブラウザで開いてください。Node.jsやパッケージのインストールは不要です。HTTPで確認する場合：

```sh
cd /workspace/kaiikokuhuku
python -m http.server 8000 --bind 0.0.0.0
```

## 計算条件

- 対象は傀異研究レベル1〜300。傀異克服モンスターの討伐数ではありません。
- 現在レベルから目標の直前のレベルまでの必要ポイントを合計し、現在レベル内で獲得済みのポイントを差し引きます。
- 周回数は必要ポイント÷1回の獲得ポイントを切り上げます。補正や報酬の変化は自動反映しません。
- 1レベルごとの必要ポイントは出発レベルに対応する内蔵の表から自動計算します。手入力は不要です。
- 必要ポイント表の出典：[まかろんのゲームメモ](https://macarongamemo.com/entry/mhrsb-anomaly_research)。出発レベル1〜10は100pt、11〜30は150pt、31〜40は200pt、41〜60は250pt、61〜80は500pt、81〜100は1000pt、101〜140は1200pt、141〜160は1300pt、161〜180は1350pt、181〜200は1400pt、201〜240は1600pt、241〜260は1650pt、261〜280は1700pt、281〜299は1800ptです。レベル1→300の累積335,200ptを出典と照合しています。
- **クエスト例の報酬値は仮定です。** 討究レベルやクエスト条件などによる報酬補正は自動計算しません。周回試算には実際のリザルトの獲得ポイントを使ってください。
- 入力は保存・送信しません。リロードすると初期値に戻ります。
- 周回候補に傀異克服オオナズチとナズチカーナ（傀異克服オオナズチ＋イヴェルカーナ）を掲載しています。この2件は未確認の報酬値を設定せず、「記録する」から実際の獲得ポイントを入力できます。
- システムフォントを使用し、外部リソースの取得は不要です。

HTML、CSS、JavaScriptのみで動作します。外部API、ログイン、ビルド処理はありません。
